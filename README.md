# Memoria de Título — Evaluación y fortalecimiento de la seguridad de software y arquitectura de la plataforma Maria.ag

Repositorio de la memoria para optar al título de Ingeniero Civil en Computación, Universidad de O'Higgins.

- **Autor:** Felipe Sebastián Suárez González
- **Profesor guía:** Edgardo Ortiz
- **Empresa:** Gota SpA

## Descripción

El trabajo consiste en una auditoría de seguridad y de la arquitectura base del software Maria.ag, de la empresa Gota SpA, con el objetivo de identificar vulnerabilidades y proponer mejoras de ciberseguridad.
