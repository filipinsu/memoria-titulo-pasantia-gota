# Investigación

Fuentes utilizadas como referencia metodológica para la auditoría de seguridad de la plataforma Maria.ag.

## OWASP Web Security Testing Guide (WSTG)

- **Enlace:** https://github.com/OWASP/wstg/tree/master/template
- **Descripción:** Guía de OWASP con la metodología estándar para realizar pruebas de seguridad web. Se utiliza como referencia para estructurar y nombrar los hallazgos (ej. WSTG-ATHN-XX para autenticación, WSTG-INPV-XX para validación de entradas).

## PortSwigger Web Security Academy

- **Enlace:** https://portswigger.net/web-security/all-topics
- **Descripción:** Recurso con explicaciones y clasificación de vulnerabilidades web comunes (inyección SQL, fuerza bruta, XSS, entre otras), usado como apoyo teórico para entender e identificar los hallazgos de este proyecto.
